Admin is switched off

The server is running without an ADMIN_TOKEN, so the admin API answers 404 on every route. That is the default: an unset secret closes the door rather than leaving it open.

To turn it on, put a token in .env and restart:

echo "ADMIN_TOKEN=$(openssl rand -hex 24)" >> .env
npm run dev
